HRD concordance in TCGA-OV (exploratory). Reproducible R analysis of a 15-gene HR/BER expression signature, genomic HRD score and overall survival. Data (not included): cBioPortal study Ovarian Serous Cystadenocarcinoma (TCGA, PanCancer Atlas), downloaded 1 September, 2026; HRD scores from file TCGA.HRD_withSampleID.txt on the NCI GDC page The Immune Landscape of Cancer (https://gdc.cancer.gov/about-data/publications/panimmune; file ID 66dd07d7-6366-4774-83c3-5ad1e22b177e; Thorsson et al., Immunity 2018, doi:10.1016/j.immuni.2018.03.023), downloaded 16 November, 2026. Run: place the data files beside the script, then Sys.setenv(HRD_COL='HRD'); source('analysis.R'). Seed 2026; R 4.6.1, GSVA 2.6.3 (outputs/sessionInfo.txt). Notes: use 06_correlation_all_with_both_scores.csv for the correlation (n = 290). 11 patients with blank survival status and 3 with a status but no survival time are excluded. Stage and residual disease are unavailable; models adjust for age, with grade as a sensitivity analysis. Findings are exploratory.
